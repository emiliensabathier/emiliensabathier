# Emilien Sabathier

Five market-finance studies, one per desk. Each asks one question, answers it on real data,
and publishes its limitations next to the result. Data frozen in the repository, report
regenerated byte-for-byte by a test, every published number pinned in the test suite.

| Study | Question | Headline | Report |
| --- | --- | --- | --- |
| [options-lab](https://github.com/emiliensabathier/options-lab) | What does S&P 500 implied volatility price? | 0 of 238 sessions with arbitrage for eSSVI under the sufficient calendar condition | [view](https://emiliensabathier.github.io/options-lab/) |
| [rates-lab](https://github.com/emiliensabathier/rates-lab) | What does the Treasury curve price: policy path, inflation, term premium? | 10y zero 4.74% = 2.47% expected short rate + 2.28% term premium | [view](https://emiliensabathier.github.io/rates-lab/) |
| [credit-lab](https://github.com/emiliensabathier/credit-lab) | Which default score flags first: Altman, Ohlson or Merton? | Null result, stated as such: 3 of 6 events testable on free data | [view](https://emiliensabathier.github.io/credit-lab/) |
| [valuation-lab](https://github.com/emiliensabathier/valuation-lab) | What growth do LVMH, Hermès, Kering and Richemont prices already imply? | Hermès prices 25.40% average growth against 12.98% normalized history | [view](https://emiliensabathier.github.io/valuation-lab/) |
| [portfolio-lab](https://github.com/emiliensabathier/portfolio-lab) | Does any allocation rule beat a static 60/40? | 0 of 4 rules do, 2010–2026, net of costs | [view](https://emiliensabathier.github.io/portfolio-lab/) |
